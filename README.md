# Sandy Portfolio

A personal portfolio website for Sanjay S featuring a cinematic dark/light theme, animated portfolio sections, and interactive UI details.

## Run locally

```bash
npm install
npm start
```

Then open http://localhost:3000

## Project structure

- `index.html` — main portfolio page
- `style.css` — styling and animations
- `script.js` — interactive behavior
- `server.js` — local Node.js server for serving the site
- `assets/` — images and media files

## GitHub use

This project is ready to be pushed to GitHub as a static portfolio repo. It includes a simple Node server so it can run locally and is compatible with hosted environments that support Node.js.
